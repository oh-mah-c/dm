High-utility itemset mining (HUIM)
 High-Utility Itemsets (HUIs)
 Each item has a weight/unit profit and can appear more than once in
each transaction (purchase quantity)
 The utility of an itemset is measured by the unit profit and purchase
quantity (e.g., profit of the itemset)
 An itemset is a HUI if its utility is no less than a user-specified
minimum utility threshold (priori knowledge)

Motivation
 It takes computations to build a UP-tree structure
 HUI-Miner is the state-of-the-art algorithm for mining
high-utility itemsets (HUIs)
 Build the utility-list structure
 Simple join operation to find the supersets of the processed
itemset
11
In this paper
 An efficient algorithm to faster discover the set of
skyline high frequency-utility itemsets (SFUIs)
 Using depth-first search
 Based on the utility-list to perform the simple join
operation for generating the supersets
 A pruning strategy is designed to early prune the unpromising
candidates
 An umax array is set to keep the maximal utility of the
frequencies to efficiently reveal the skyline points

Conclusion
 Present an efficient algorithm to find the set of skyline
points
 Considering both frequency and utility factors
 Three mechanisms
 Adopt the utility-list to perform the simple operation for finding
the supersets of the itemsets
 An umax array is used to keep the maximal utility of frequencies
 A pruning strategy is used to reduce the search space based on the
utility-list
 Better performance than the state-of-the-art SKYMINE algorithm
