# Third Party Notices

This project contains an unofficial C inference port of Swin Transformer. The implementation is architecturally based on the official Microsoft Swin-Transformer repository and is validated against TensorFlow/Keras reference fixtures for integration with this repository's TensorFlow-core-style DM_Block runtime.
