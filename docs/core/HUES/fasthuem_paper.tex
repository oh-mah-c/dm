\section{Problem definition}\label{sec:problem}

We adopt the redefined problem of \HUESpan{} \cite{fournier2019huespan} without change. A complex event sequence is
$\mathit{CES} = \langle (\mathit{tSE}_{t_1}, t_1), \dots, (\mathit{tSE}_{t_n}, t_n)\rangle$ with $t_1 < \dots < t_n$, where each
$\mathit{tSE}_{t_i}$ is a set of events. Each event $e$ has an external utility $p(e) > 0$ and, at time $t_i$, an internal utility
$q(e, t_i) > 0$; $u(e, t_i) = p(e)\, q(e, t_i)$ and $u(SE, t_i) = \sum_{e \in SE} u(e, t_i)$.

\begin{definition}[Episode, occurrence, minimal occurrence {\cite[Defs.~2--4]{fournier2019huespan}}]
An episode is $\alpha = \langle SE_1, \dots, SE_k\rangle$ with non-empty event sets $SE_i$. An interval $[t_s, t_e]$ is an occurrence of $\alpha$ if $\alpha$ occurs in it with $SE_1$ at $t_s$ and $SE_k$ at $t_e$; it is minimal if no other occurrence of $\alpha$ is a sub-interval of it. $\mathit{moSet}(\alpha)$ denotes the set of minimal occurrences.
\end{definition}

\begin{definition}[Redefined utility {\cite[Def.~12]{fournier2019huespan}}]
For a minimal occurrence $[t_s, t_e]$ of $\alpha = \langle SE_1, \dots, SE_k\rangle$,
$u(\alpha, [t_s, t_e]) = u(SE_1, t_s) + \sum_{i=2}^{k-1} \max_x u(SE_i, t_{g(i)_x}) + u(SE_k, t_e)$,
where the maximum ranges over the time points at which $SE_i$ can be matched in the occurrence; $u(\alpha) = \sum_{mo \in \mathit{moSet}(\alpha)} u(\alpha, mo)$.
\end{definition}

\begin{definition}[Maximum duration and problem {\cite[Defs.~13--14]{fournier2019huespan}}]
A minimal occurrence satisfies the maximum duration if $t_e - t_s + 1 \le \mathit{maxDur}$ (the printed Definition~13 reads $t_e - t_e + 1$, an evident typo; the reference implementation uses $t_s + \mathit{maxDur} - 1$ as the last admissible time point). Given $\mathit{minUtil}$ and $\mathit{maxDur}$, the task is to find every episode with $u(\alpha) \ge \mathit{minUtil}$, counting only minimal occurrences that satisfy $\mathit{maxDur}$. In \cite{fournier2019huespan} and in its implementation, $\mathit{minUtil}$ is a fraction of the total utility of the sequence.
\end{definition}

\noindent\open{Definition 12 does not state how the candidate time points $t_{g(i)_x}$ of the middle event sets are restricted (e.g. whether the choices for different $i$ must respect the order of the episode). The reference implementation computes the maximum with a finite-state procedure (\texttt{ComplexSequence.getMaximalUtility}) and only during serial extensions. A brute-force oracle following the text of Definition~12 is needed before the reference implementation can be called correct with respect to the paper (Section~\ref{sec:plan}).}

\section{Existing upper bounds}\label{sec:bounds}

For a minimal occurrence $[t_s, t_e]$ of $\alpha = \langle SE_1, \dots, SE_k\rangle$ satisfying $\mathit{maxDur}$, with $\mathit{tu}(t)$ the total utility of the events at $t$:
\begin{align}
\EWU(\alpha, [t_s, t_e]) &= \sum_{i=1}^{k-1} u(SE_i, t_{g(i)}) + \sum_{j=t_e}^{t_s + \mathit{maxDur} - 1} \mathit{tu}(j) && \text{\cite[Def.~16]{fournier2019huespan}}\\
\ERU(\alpha, [t_s, t_e]) &= \sum_{i=1}^{k} u(SE_i, t_{g(i)}) + u(\mathit{rSE}_{t_e}, t_e) + \sum_{j=t_e+1}^{t_s + \mathit{maxDur} - 1} \mathit{tu}(j) && \text{\cite[Def.~18]{fournier2019huespan}}
\end{align}
where $u(\mathit{rSE}_{t_e}, t_e)$ is the utility of the events at $t_e$ that follow the last event of $SE_k$ in the processing order. Both bounds are already restricted to the duration horizon $t_s + \mathit{maxDur} - 1$; summed over $\mathit{moSet}(\alpha)$ they bound the utility of every super-episode obtained by concatenations \cite[Lemma~1]{fournier2019huespan}. The reference implementation computes ERU exactly in this form (utility of the occurrence, \texttt{getIrutil} at $t_e$, and the total utility of $[t_e + 1, t_s + \mathit{maxDur} - 1]$).

\begin{example}[Correction of the earlier running example]
In the sequence of the earlier draft ($A$ at $t=1,4,7$ with utilities 10, 5, 15; $B$ at $t=2,4,6,8$; $\mathit{maxDur} = 4$; $\mu = 35$), the episode $\gamma = \langle A, B, B\rangle$ has the single valid minimal occurrence $[1,4]$ ($A$ at 1, $B$ at 2 and 4). Definition~16 gives $\EWU(\gamma) = u(A,1) + u(B,2) + \mathit{tu}(4) = 10 + 3 + 11 = 24 < 35$, so \HUESpan{} also prunes $\gamma$. The earlier value 101 summed $\mathit{tu}(5), \dots, \mathit{tu}(10)$, which lie beyond the horizon $1 + 4 - 1 = 4$ and are not part of EWU.
\end{example}

\section{The proposed bound RDUB is not valid for this problem}\label{sec:rdub}

The earlier draft replaced, for each future time point in the horizon, the total utility $\mathit{tu}(t)$ by the largest single-event utility $\max_{e} u(e, t)$. This is not an upper bound when an extension may contain several events at the same time point, which the episodes of \HUESpan{} allow (simultaneous concatenation).

\begin{proposition}
The bound $\RDUB(\alpha) = \sum_{mo} [u(\alpha, mo) + \sum_{t \in (t_e,\, t_s + \mathit{maxDur} - 1]} \max_e u(e,t)]$ can be smaller than the utility of a super-episode of $\alpha$.
\end{proposition}
\begin{proof}
Let $\mathit{CES} = \langle (\{A\}, 1), (\{B, C\}, 2)\rangle$ with $u(A,1) = 1$, $u(B,2) = u(C,2) = 5$, $\mathit{maxDur} = 2$ and $\mu = 10$. Then $\RDUB(\langle A\rangle) = 1 + 5 = 6 < \mu$, so $\langle A\rangle$ and its super-episodes would be pruned, but $\langle (A), (B C)\rangle$ has the minimal occurrence $[1,2]$ and utility $1 + 10 = 11 \ge \mu$.
\end{proof}

\noindent For serial episodes with one event per position, the per-time-point maximum is a plausible bound, but that is a different (restricted) problem, for which \HUESpan{} is not the natural baseline, and the earlier proof relied on the unproven claim that every minimal occurrence of an extension extends a minimal occurrence of the prefix with the same prefix utility. \open{whether any tightening of ERU remains valid for complex episodes, and by how much it can reduce the search; the slack of ERU (ERU minus the utility actually reached by extensions) has not been measured.}

\section{Research plan}\label{sec:plan}

\begin{enumerate}
\item \textbf{Oracle.} Brute-force enumeration of episodes and minimal occurrences on small random sequences, with the utility of Definition~12 computed by exhaustive search over the admissible time points; compare with the \HUESpan{} reference implementation. Any difference must be reported with a minimal counterexample.
\item \textbf{Parity.} Complete the randomized parity test of the C port against the Java code (all six flag configurations).
\item \textbf{Slack measurement.} Instrument the port to record, per expanded episode, ERU and the largest utility reached in its subtree, to determine whether a tighter bound can matter before designing one.
\item \textbf{Fair comparison.} Any new algorithm is compared with the C port of \HUESpan{} in the same framework (same language, same input parsing), on the datasets of \cite{fournier2019huespan} (Retail, Kosarak, T25I10N1KD10KQ10F5 with synthetic utilities); the generation procedure and seeds of the utilities must be documented. Platform: Intel Core i7-10700, 32~GiB RAM, Ubuntu 24.04, GCC 13.3, single thread.
\end{enumerate}
